旅食Navi プライバシーポリシー・利用規約

最終更新: 2026-09-14　運営: 個人（GitHub: inotaka1979）

1. このアプリについて

旅食Navi（以下「本アプリ」）は、出張・旅先で飲食店を探し、行った人が採点を共有するための無料の個人開発アプリです。営利目的の運営や広告配信は行っていません。

2. 取得する情報

  • 採点データ: 店名、所在地（都道府県・エリア・駅）、採点、行った日、料理名、リンク、写真の縮小版（長辺 480px・3 枚まで）、表示名（自己申告のニックネーム）。共有データベース（Google Firebase Firestore、東京リージョン）に保存され、本アプリを開いた全員が閲覧できます。
  • 位置情報: 「現在地」「現在地から近い順」「周辺の店」を使うときだけ、端末の許可を得て取得します。サーバーには送信・保存せず、周辺店の検索条件（緯度経度）として外部 API に渡すのみです。
  • 端末内データ: 写真の元サイズ、下書き、行きたいリスト、絞り込み設定、最近見た店は端末の中（localStorage / IndexedDB）にだけ保存され、外部には送られません。
  • 匿名認証: 共有データベースへの書き込みのため、Firebase の匿名ログインを使います。氏名・メールアドレス・電話番号などの個人情報は取得しません。

3. 外部サービスの利用

  • Google Firebase（データ保存・匿名認証）
  • ホットペッパーグルメ Web サービス（周辺の飲食店情報。Powered by ホットペッパーグルメ Webサービス）
  • Yahoo! JAPAN ローカルサーチ API（周辺の飲食店情報）
  • OpenStreetMap（地図タイル・店舗データ。© OpenStreetMap contributors）
  • Google マップ（経路案内・店舗検索へのリンク）
  • GitHub Pages（ページの配信）

各サービスへは、周辺店の検索に必要な緯度経度や店名のみを送ります。各サービスの利用条件はそれぞれの規約に従います。

4. 情報の利用目的

飲食店の検索・採点の表示、周辺店の案内、味覚の近さによる予測点の計算にのみ利用します。第三者への販売・提供は行いません。

5. 削除について

自分が投稿した採点は、店ページの「削除」でいつでも消せます（共有データベースからも削除されます）。端末内のデータはブラウザの設定から削除できます。

6. 利用規約

  • 採点は行った人の主観による参考情報であり、正確性・最新性を保証しません。
  • 他人を誹謗中傷する内容、虚偽の採点、店や個人の権利を侵害する写真の投稿は禁止します。運営者の判断で削除することがあります。
  • 本アプリの利用により生じた損害について、運営者は責任を負いません。
  • 予告なく機能の変更・提供の終了を行うことがあります。
